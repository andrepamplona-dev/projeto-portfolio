# 🌐 Website Portfolio

Este é um site de portfólio desenvolvido para apresentar nossos projetos de forma visual, moderna e responsiva. O objetivo é destacar trabalhos relevantes na área de desenvolvimento e design, oferecendo uma experiência agradável para visitantes e recrutadores.

- Seção de destaques de projetos

- Navegação clara e objetiva
